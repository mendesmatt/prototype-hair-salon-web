# Hair Atelier — Premium Salon Website

> Interactive frontend prototype for premium hair salons and beauty studios, built around the in-salon experience.

`HTML5` · `CSS3` · `JavaScript` · `Tailwind CSS (CDN)`

## 🇬🇧 English

**Segment:** Hair salon & beauty studio

Interactive frontend prototype for premium hair salons and beauty studios, built around the in-salon experience.

**Highlights**

- Service menu and salon experience narrative
- Stylist profiles with credentials and specialities
- Booking call-to-action and studio credentials

**Tech:** HTML5, CSS3, vanilla JavaScript, Tailwind CSS via CDN.

**Run it:** Open `index.html` in any modern browser — no build step, no dependencies to install.

_This is a design prototype: data is mocked in the front-end and there is no back-end._
